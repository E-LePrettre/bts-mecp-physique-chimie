# 21 – Objectifs et ressources

Cette séance introduit la **conductivité σ** et ses applications en contrôle qualité cosmétique : type d'émulsion, suivi de stabilité, et CMC.

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Conductivité σ** | Capacité d'une solution à conduire le courant, grâce aux ions |
| **Facteurs influençant σ** | Concentration, nature des ions, température, solvant |
| **Type d'émulsion** | H/E (σ élevée) vs E/H (σ faible) selon la phase continue |
| **Stabilité** | Suivi σ = f(t) pour détecter une inversion de phase |
| **CMC** | Concentration micellaire critique, rupture de pente sur σ = f(C) |
| **Conformité CQ** | Comparaison σ mesurée vs cahier des charges |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Dissociation ionique (S11), lien ions ↔ conductivité |
| **Analyser** | Tableaux de σ, courbes σ = f(C), données CQ |
| **Interpréter** | Variation de σ → modification composition / type d'émulsion |
| **Argumenter** | Au moins 2 arguments pour justifier un diagnostic CQ |
| **Décider** | Conformité / non-conformité, type d'émulsion, recommandation |

## 🔬 La conductivité – Rappel visuel

```
        CONDUCTIVITÉ σ
        
        Mesure la capacité d'une solution à conduire le courant
        Unité : S/m (ou µS/cm en cosmétique)
        
        ───────────────────────────────────────────────────────────
        
        FACTEURS
        
        Concentration ions ↑  →  σ ↑
        Petits ions mobiles   →  σ ↑
        Température ↑         →  σ ↑
        Solvant polaire       →  σ ↑
        
        ───────────────────────────────────────────────────────────
        
        APPLICATIONS CQ
        
        σ > 50 µS/cm  →  Émulsion H/E (phase continue = eau)
        σ < 10 µS/cm  →  Émulsion E/H (phase continue = huile)
        σ chute brutale →  Inversion de phase (instabilité)
        Rupture de pente sur σ = f(C)  →  CMC
```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Plus d'ions → σ plus élevée | Interpréter une mesure de conductivité |
| Eau pure ≈ 0, huile ≈ 0 | Seules les solutions ioniques conduisent |
| σ > 50 µS/cm → H/E | Identifier le type d'émulsion |
| σ < 10 µS/cm → E/H | Identifier le type d'émulsion |
| Chute brutale de σ → inversion de phase | Suivi de stabilité CQ |
| Rupture de pente sur σ = f(C) → CMC | Déterminer la concentration optimale en tensioactif |
| Toujours noter la température | Comparer des mesures CQ (σ dépend de T) |

---

## 🧴 Pourquoi c'est essentiel en cosmétique ?

| Application | Exemple |
|-------------|---------|
| **Identifier le type d'émulsion** | Crème H/E (σ ≈ 900 µS/cm) vs baume E/H (σ ≈ 4 µS/cm) |
| **Suivre la stabilité** | σ chute de 860 à 8 µS/cm → inversion de phase → lot non conforme |
| **Déterminer la CMC** | Rupture de pente sur σ = f(C) → concentration optimale en SDS |
| **Contrôle qualité** | σ mesurée vs cahier des charges → lot conforme ou rejeté |
| **Vérifier la formulation** | σ trop basse → insuffisance d'ions → erreur de pesée ? |

## 💡 Exemples cosmétiques

| Produit | Type | σ typique | Ce que σ nous apprend |
|---------|:----:|:---------:|----------------------|
| **Crème de jour légère** | H/E | 800–1 200 µS/cm | Phase aqueuse continue, riche en ions |
| **Lait démaquillant** | H/E | 900–1 500 µS/cm | Facile à rincer (phase aqueuse) |
| **Baume à lèvres** | E/H | 2–8 µS/cm | Film occlusif (phase huileuse continue) |
| **Cold cream** | E/H | 1–5 µS/cm | Protection longue durée |
| **Sérum physiologique** | Solution | 15 400 µS/cm | Très riche en ions (NaCl 9 g/L) |
| **Eau purifiée** | Solution | ≈ 1 µS/cm | Quasi aucun ion |
