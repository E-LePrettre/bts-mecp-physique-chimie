# 12 – Objectifs et ressources

Cette séance introduit les **représentations de Lewis** et la notion de **stabilité chimique**. Les élèves apprennent à lire une formule de Lewis pour identifier les zones de fragilité d'une molécule, notamment les liaisons O–O et S–S présentes dans de nombreux actifs cosmétiques.

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Gaz nobles** | Éléments stables (colonne 18) : couche externe complète |
| **Règle de l'octet/duet** | Stabilité avec 8 e⁻ (ou 2 pour H) sur la couche externe |
| **Formule de Lewis** | Représentation des électrons de valence |
| **Doublet liant** | Paire d'électrons partagée entre deux atomes (liaison) |
| **Doublet non liant** | Paire d'électrons appartenant à un seul atome |
| **Radical** | Espèce avec un électron célibataire (instable, réactif) |
| **Liaisons fragiles** | Liaisons O–O et S–S facilement cassées |
| **ROS** | Espèces réactives de l'oxygène (radicaux libres) |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Appliquer la règle de l'octet pour lire une formule de Lewis |
| **Interpréter** | Identifier les zones de fragilité sur une molécule |
| **Argumenter** | Justifier l'instabilité d'une molécule par sa structure |
| **Communiquer** | Utiliser le vocabulaire (radical, doublet, liaison fragile) |

## 🔬 La règle de l'octet – Rappel visuel

```
        STABILITÉ = COUCHE EXTERNE COMPLÈTE
        
        Règle du DUET (H, He) :     2 électrons
        Règle de l'OCTET (autres) : 8 électrons
        
        ┌─────────────────────────────────────┐
        │  Gaz nobles = configuration idéale  │
        │  He (2 e⁻), Ne (8 e⁻), Ar (8 e⁻)   │
        └─────────────────────────────────────┘
```

## 🧪 Liaisons fragiles en cosmétique

| Liaison | Exemple de molécule | Présence en cosmétique |
|:-------:|---------------------|------------------------|
| **O–O** | Peroxyde de benzoyle | Actif anti-acné |
| **O–O** | Peroxydes (H₂O₂) | Décoloration capillaire |
| **S–S** | Cystine (kératine) | Structure du cheveu |
| **S–S** | Glutathion oxydé | Antioxydant |

## ⚠️ Les radicaux libres (ROS)

```
        RADICAL = électron célibataire = INSTABLE
        
        Exemples de ROS :
        • HO•   (radical hydroxyle)
        • O₂•⁻  (anion superoxyde)
        • ROO•  (radical peroxyle)
        
        ┌─────────────────────────────────────────┐
        │  Les radicaux attaquent les molécules   │
        │  → Vieillissement cutané                │
        │  → Dégradation des cosmétiques          │
        └─────────────────────────────────────────┘
```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Octet respecté | Molécule **stable** |
| Électron célibataire | **Radical** (très réactif) |
| Liaison O–O | **Fragile** (se casse facilement) |
| Liaison S–S | **Fragile** (permanente, défrisage) |
| Doublet non liant | Ne participe pas à la liaison |
