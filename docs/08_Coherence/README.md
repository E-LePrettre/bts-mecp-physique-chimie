# 08 – Objectifs et ressources

Cette séance développe l'**esprit critique** face aux résultats expérimentaux. Les élèves apprennent à vérifier la cohérence d'un résultat, identifier une valeur aberrante et justifier une décision de contrôle qualité. Cette compétence est très valorisée à l'épreuve E2.

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Analyse dimensionnelle** | Vérifier un calcul par ses unités |
| **Ordre de grandeur** | Détecter une erreur grossière |
| **Moyenne** | Calculer la valeur centrale d'une série |
| **Dispersions simples** | Mesurer la dispersion des mesures |
| **Valeur aberrante** | Identifier et traiter une mesure suspecte |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Analyser** | Critiquer un jeu de résultats |
| **Interpréter** | Donner du sens à une série de mesures |
| **Argumenter** | Justifier une décision (valider/rejeter) |
| **Communiquer** | Rédiger une recommandation professionnelle |

## 📊 Ordres de grandeur à retenir

| Grandeur | Valeur typique | Valeur suspecte |
|----------|:--------------:|:---------------:|
| Concentration d'actif | 1 à 200 g/L | > 500 g/L |
| pH cutané | 4 à 8 | < 2 ou > 12 |
| Densité d'une huile | 0,85 à 0,96 | < 0,5 ou > 1,5 |
| Masse volumique de l'eau | ≈ 1,00 g/mL | ≠ 1,00 |

---
## 🔧 Formules à retenir

| Formule                                 | Utilisation                                       |
| --------------------------------------- | ------------------------------------------------- |
| $x̄ = \frac{Σxᵢ}{n}$                      | Calculer la moyenne                               |
| $x_{min} = min(xᵢ)$                   | Déterminer la plus petite valeur de la série      |
| $x_{max} = max(xᵢ)$                     | Déterminer la plus grande valeur de la série      |
| $E = x_{max} − x_{min}$                   | Calculer l’étendue (dispersion simple)            |
| $\Delta = \|x − x_{ref}\|$                     | Calculer l’écart absolu à une valeur de référence |
| $\varepsilon_r = \frac{\|x − x_{ref}\|}{x_{ref}} × 100$ | Calculer l’écart relatif (en %)                   |
