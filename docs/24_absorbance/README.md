
# 24 – Objectifs et ressources

Cette séance est de type **🧭 Culture appareils** : elle introduit la spectrophotométrie UV-visible et la loi de Beer-Lambert, outils fondamentaux du contrôle qualité cosmétique. 

---

## 🎯 Objectifs

### Notions abordées

| Notion | Contenu |
|--------|---------|
| **Spectre EM** | Domaines UV (UVA, UVB, UVC), visible, IR ; distinction avec ondes mécaniques (S23) |
| **Spectrophotomètre** | Principe (lampe → monochromateur → cuve → détecteur), absorbance A, transmittance T |
| **Spectre d'absorption** | Graphe A = f(λ), λ_max, lien spectre-couleur |
| **Loi de Beer-Lambert** | A = ε × l × C ; proportionnalité absorbance-concentration |
| **Dosage spectrophotométrique** | Courbe d'étalonnage A = f(C), lecture graphique, conclusion conformité |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Connaître A, ε, l, C et énoncer Beer-Lambert |
| **Analyser** | Lire un spectre UV-vis, extraire λ_max, lire une courbe d'étalonnage |
| **Interpréter** | Relier A à C, conclure conformité au CDC |
| **Argumenter** | Justifier une conclusion CQ (2 arguments) |
| **Communiquer** | Présenter un résultat de dosage avec unités et interprétation |

## 💡 Points d'attention 

**Séance pivot :** Beer-Lambert est une formule qui sera réinvestie dans les évaluations E2 suivantes. Elle est essentielle d'être maîtriser par le calcul C = A / (ε × l) et par la lecture graphique d'une courbe d'étalonnage.

**Lien avec S05 :** La courbe d'étalonnage reprend exactement le même principe que l'échelle de teinte vue en S05 (plus c'est concentré, plus c'est « foncé »), mais de manière quantitative. Faire ce rappel explicite aide les élèves à ancrer la notion.

**Confusion fréquente UV / ultrasons :** UV = onde EM (pas de milieu, pas de gel), US = onde mécanique (milieu et gel obligatoires).

**Pièges calcul :** Les unités de ε (L·mol⁻¹·cm⁻¹) déstabilisent.
