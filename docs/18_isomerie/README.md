# 18 – Objectifs et ressources

Cette séance introduit l'**isomérie de constitution** : le fait que deux molécules peuvent avoir la même formule brute mais des structures différentes. 

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Isomère** | Molécule ayant la même formule brute qu'une autre mais une structure différente |
| **Isomérie de constitution** | Isomères dont l'enchaînement des atomes est différent |
| **Isomérie de chaîne** | Chaînes carbonées de formes différentes (linéaire, ramifiée, cyclique) |
| **Isomérie de position** | Même groupe fonctionnel, positions différentes sur la chaîne |
| **Isomérie de fonction** | Groupes fonctionnels différents |
| **Lien structure-propriété** | Structure différente → propriétés différentes |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Définir l'isomérie, identifier les trois types |
| **Analyser** | Comparer deux formules topologiques, identifier les différences |
| **Interpréter** | Relier structure (isomérie) à propriété (T_ébullition, texture, activité) |
| **Argumenter** | Justifier le choix d'un isomère pour une application cosmétique |

## 🔬 Isomérie de constitution – Rappel visuel

```
        MÊME FORMULE BRUTE, STRUCTURES DIFFÉRENTES
        
        Exemple : C₄H₁₀
        
        BUTANE                      ISOBUTANE
        (linéaire)                  (ramifié)
        
           \/\                          |
                                       / \
        
        Tébullition = –0,5 °C      Tébullition = –11,7 °C
        
        → Propriétés DIFFÉRENTES
```

---

## 🔗 Les trois types d'isomérie

```
        ISOMÉRIE DE CHAÎNE
        Forme de la chaîne carbonée différente
        Exemple : pentane (linéaire) vs isopentane (ramifié)
        
        ISOMÉRIE DE POSITION
        Même fonction, position différente
        Exemple : propan-1-ol (OH en C1) vs propan-2-ol (OH en C2)
        
        ISOMÉRIE DE FONCTION
        Groupes fonctionnels différents
        Exemple : éthanol (alcool –OH) vs méthoxyméthane (éther –O–)
```

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Même formule brute + structures différentes = isomères | Identifier des isomères |
| Chaîne linéaire → T_ébullition plus haute | Comparer des isomères de chaîne |
| Chaîne ramifiée → texture plus légère | Choisir un émollient cosmétique |
| Isomérie de chaîne → propriétés physiques différentes | Prévoir T_ébullition, viscosité |
| Isomérie de fonction → propriétés radicalement différentes | Alcool vs éther : état physique, solubilité |

---

## 🧴 Pourquoi c'est essentiel en cosmétique ?

| Situation | Importance de l'isomérie |
|-----------|--------------------------|
| **Fiche technique** | Toujours indiquer la formule topologique (pas juste la formule brute) |
| **Choix d'actif** | Menthol (rafraîchissant) ≠ Isomenthol (peu actif) |
| **Choix d'émollient** | Linéaire (épais, occlusif) ≠ Ramifié (léger, pénétrant) |
| **Contrôle qualité** | Vérifier la structure exacte, pas juste le nombre d'atomes |

---

## 💡 Exemples cosmétiques

| Paire d'isomères | Type | Différence de propriété |
|------------------|:----:|-------------------------|
| **Acide stéarique** (linéaire) vs **Isostéarate** (ramifié) | Chaîne | Texture : épais vs léger |
| **Menthol** vs **Isomenthol** | Stéréo | Activité rafraîchissante : forte vs faible |
| **Rétinol** vs **Isotrétinoïne** | Position | Activité et toxicité différentes |

## ⚠️ Conseils pédagogiques

### Points de vigilance

- **Comparaison visuelle** : fournir version colorée des formules topologiques (chaîne principale en rouge, ramifications en bleu)
- **Confusion position/fonction** : insister sur « même fonction, endroit différent » vs « fonction différente »
- **Lien structure-propriété** : multiplier les exemples cosmétiques concrets

### Différenciation

- **Groupe fragile** : modèles moléculaires pour visualiser les isomères ; tableau récapitulatif des trois types
- **Groupe avancé** : dessiner tous les isomères de C₅H₁₂ (3 isomères : pentane, isopentane, néopentane)
