# ✅ MOBILISER (4 points)

> *Utiliser les connaissances scientifiques et les outils appropriés*

## Connaissances à mobiliser (S01-S05)

| ✓ | Je sais... |
|---|------------|
| ☐ | Distinguer **corps pur** et **mélange** |
| ☐ | Distinguer mélange **homogène** et **hétérogène** |
| ☐ | Définir **solution**, **solvant**, **soluté** |
| ☐ | Expliquer ce qu'est la **dissolution** (≠ fusion !) |
| ☐ | Définir la **solubilité** et ses 3 facteurs (T°, nature solvant, nature soluté) |
| ☐ | Distinguer **miscibilité** (liquides) et **solubilité** (solide dans liquide) |
| ☐ | Définir la **concentration massique** Cm |
| ☐ | Expliquer ce qu'est une **dilution** (ajouter du solvant, pas du soluté) |
| ☐ | Expliquer pourquoi la **quantité de soluté est conservée** lors d'une dilution |

## Formules à connaître

| ✓ | Formule | Utilisation |
|---|---------|-------------|
| ☐ | **Cm = m / V** | Calculer une concentration |
| ☐ | **m = Cm × V** | Calculer une masse à peser |
| ☐ | **V = m / Cm** | Calculer un volume à préparer |
| ☐ | **Cm × Vm = Cf × Vf** | Relation de conservation (dilution) |
| ☐ | **Vm = (Cf × Vf) / Cm** | Calculer le volume à prélever |
| ☐ | **F = Cm / Cf = Vf / Vm** | Facteur de dilution |

# 🔴 ERREURS FRÉQUENTES À ÉVITER

## Erreurs de calcul

| ❌ Erreur | ✅ Correction |
|----------|--------------|
| Oublier de convertir mL en L | Toujours écrire : V = ... mL = ... L |
| Résultat sans unité | Toujours écrire l'unité : Cm = 50 **g/L** |
| Inverser Cm et Cf | Cm = mère (concentrée), Cf = fille (diluée) |
| Ne pas vérifier par F | Toujours calculer F de 2 façons |

## Erreurs de vocabulaire

| ❌ Erreur | ✅ Correction |
|----------|--------------|
| "Le sucre a fondu" | "Le sucre s'est **dissous**" |
| "On mélange le soluté" | "On **dissout** le soluté" |
| "On ajoute de l'eau pour diluer le soluté" | "On ajoute de l'eau pour diluer **la solution**" |
| "La solution est miscible" | "Les deux **liquides** sont miscibles" |

## Erreurs de rédaction

| ❌ Erreur | ✅ Correction |
|----------|--------------|
| Réponse sans justification | Ajouter "car..." ou "en effet..." |
| Calcul sans interprétation | Ajouter une phrase de conclusion |
| "C'est bon" / "C'est conforme" | "Le produit est **conforme au cahier des charges [X ; Y]**" |
