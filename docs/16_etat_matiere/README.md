# 16 – Objectifs et ressources

Cette séance introduit les **états de la matière**, le **diagramme d'état**, les **transferts thermiques** et approfondit la **variabilité statistique** (écart-type, histogramme). 

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **États de la matière** | Solide, liquide, gaz |
| **Changements d'état** | Fusion, solidification, vaporisation, liquéfaction, sublimation, condensation |
| **Diagramme d'état** | Représentation graphique de l'état en fonction de (P, T) |
| **Pression** | Influence sur les températures de changement d'état |
| **Transferts thermiques** | Conduction (contact), convection (fluide), rayonnement (ondes) |
| **Variabilité statistique** | Écart-type (σ), histogramme, répétabilité |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Nommer les changements d'état, identifier les modes de transfert thermique |
| **Analyser** | Lire un diagramme d'état (P, T), interpréter un histogramme |
| **Interpréter** | Relier P, T aux conditions de procédé ; critiquer la fiabilité d'une série (σ/x̄) |
| **Argumenter** | Justifier un choix de température de stockage, de mode de chauffage |

## 🔬 Diagramme d'état – Rappel visuel

![diagramme d'état](.\images\Diag_eau.svg.png)

        
        Lecture à P = 1 atm (ligne horizontale) :
        • T < T₁ → SOLIDE
        • T₁(=0) < T < T₂(=100) → LIQUIDE
        • T > T₂ → GAZ
        
        Si P augmente → T de changement d'état augmente

## 📊 Variabilité statistique – Rappel visuel

```
        ÉCART-TYPE (σ) = mesure de la DISPERSION
        
        σ/x̄ < 5%    → Excellente répétabilité ✅
        σ/x̄ = 5-10% → Répétabilité acceptable ⚠️
        σ/x̄ > 10%   → Mauvaise répétabilité ❌
        
        HISTOGRAMME = visualisation de la répartition
        
        • Distribution symétrique → pas de biais
        • Valeur isolée → aberrante (à vérifier)
        • Plusieurs pics → plusieurs populations
```

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| P augmente → T changement d'état augmente | Autoclave : 120 °C à 2 bar |
| Conduction = contact | Pot métallique sur plaque |
| Convection = fluide | Bain-marie, air chaud |
| Rayonnement = ondes | Lampe IR, four radiant |
| σ petit → répétabilité bonne | Valider les mesures |
| σ grand → répétabilité mauvaise | Revoir le protocole |
