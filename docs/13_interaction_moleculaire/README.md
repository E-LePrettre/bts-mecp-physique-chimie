# 13 – Objectifs et ressources

Cette séance introduit les **interactions intermoléculaires** (liaisons hydrogène, Van der Waals) et leur lien avec la **solubilité** et la **pénétration cutanée**. Les élèves apprennent à relier la structure d'une molécule (polaire/apolaire) à son comportement face à la barrière lipidique de la peau.

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Électronégativité** | Capacité d'un atome à attirer les électrons d'une liaison |
| **Liaison polaire / apolaire** | Différence d'électronégativité Δχ > 0,4 → polaire |
| **Molécule polaire / apolaire** | Dépend des liaisons ET de la géométrie |
| **Liaison hydrogène** | Interaction X–H ··· Y (X, Y = O, N, F) |
| **Van der Waals** | Interactions faibles entre toutes les molécules |
| **Hydrophile / Lipophile** | Affinité pour l'eau (polaire) / pour les graisses (apolaire) |
| **Pénétration cutanée** | Traversée du ciment lipidique (apolaire) du stratum corneum |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Calculer Δχ, identifier polarité et type d'interaction |
| **Argumenter** | Justifier solubilité et pénétration par la structure moléculaire |

## 🔬 Polarité et interactions – Rappel visuel

```
        POLARITÉ D'UNE LIAISON
        
        Δχ > 0,4  →  Liaison POLAIRE
        Δχ ≤ 0,4  →  Liaison APOLAIRE
        
        ┌─────────────────────────────────────────┐
        │  O–H (Δχ=1,2) → POLAIRE                 │
        │  C–H (Δχ=0,4) → APOLAIRE                │
        │  C–C (Δχ=0)   → APOLAIRE                │
        └─────────────────────────────────────────┘
```

## 🧪 Interactions et solubilité en cosmétique

| Interaction | Entre quelles molécules ? | Exemple cosmétique |
|:-----------:|---------------------------|---------------------|
| **Liaison H** | Polaires (O–H, N–H) | Vitamine C dans l'eau |
| **Van der Waals** | Apolaires (chaînes C–H) | Vitamine E dans l'huile |

## ⚠️ Pénétration cutanée : le rôle du ciment lipidique

```
        CIMENT LIPIDIQUE = APOLAIRE
        
        Conséquences :
        • Lipophile  → PÉNÈTRE (Van der Waals)
        • Hydrophile → BLOQUÉ (incompatible)
        • Amphiphile → PÉNÈTRE (partie apolaire)
        
        ┌─────────────────────────────────────────────┐
        │  Stratégies pour les hydrophiles :          │
        │  → Dérivé lipophile (chaînes grasses)       │
        │  → Liposomes                                │
        │  → Émulsion huile-dans-eau                  │
        │  → Promoteurs d'absorption                  │
        └─────────────────────────────────────────────┘
```

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Δχ > 0,4 | Liaison **polaire** |
| Liaison H | Entre molécules **polaires** (O–H, N–H) |
| Van der Waals | Entre **toutes** les molécules (seule force entre apolaires) |
| Polaire dissout polaire | Vitamine C → soluble dans l'eau |
| Apolaire dissout apolaire | Vitamine E → soluble dans l'huile |
| Ciment lipidique = apolaire | Lipophiles pénètrent, hydrophiles bloqués |
