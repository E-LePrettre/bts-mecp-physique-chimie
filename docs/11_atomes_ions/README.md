# 11 – Objectifs et ressources

Cette séance introduit la **structure de l'atome** et les **ions**, éléments fondamentaux pour comprendre ce que mesurent réellement les appareils de contrôle qualité (pH-mètre, conductimètre). 

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Atome** | Constituant élémentaire de la matière (noyau + électrons) |
| **Électrons de valence** | Électrons de la couche externe, responsables des liaisons |
| **Tableau périodique** | Classification des éléments par propriétés |
| **Ion** | Atome ayant gagné ou perdu des électrons |
| **Cation / Anion** | Ion positif (perte e⁻) / Ion négatif (gain e⁻) |
| **Électroneutralité** | Équilibre des charges dans un composé ionique |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Utiliser le tableau périodique pour trouver Z et les électrons de valence |
| **Interpréter** | Relier la présence d'ions à une mesure (pH, conductivité) |
| **Argumenter** | Justifier la formation d'un ion à partir de la structure électronique |
| **Communiquer** | Utiliser le vocabulaire scientifique (cation, anion, électroneutralité) |

## 🔬 Structure de l'atome – Rappel visuel

```
                    ATOME
                      │
        ┌─────────────┴─────────────┐
        │                           │
      NOYAU                    ÉLECTRONS (e⁻)
   (protons + neutrons)         charge : -
    charge : +                  autour du noyau
        │
        │
   Numéro atomique Z
   = nombre de protons
   = nombre d'électrons
     (atome neutre)
```

## 🧪 Ions courants en cosmétique

| Ion | Formule | Origine / Utilisation |
|-----|:-------:|----------------------|
| Sodium | Na⁺ | Conservateurs (benzoate de sodium) |
| Potassium | K⁺ | Régulateur, émollient |
| Calcium | Ca²⁺ | Dureté de l'eau, actif reminéralisant |
| Chlorure | Cl⁻ | Sel (NaCl), conservateurs |
| Hydroxyde | OH⁻ | Ajusteur de pH (soude) |
| Hydronium | H₃O⁺ | Acidité, pH |

---

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Atome neutre | Nombre de protons = Nombre d'électrons |
| Cation (+) | Atome qui a **perdu** des électrons |
| Anion (−) | Atome qui a **gagné** des électrons |
| Électroneutralité | Somme des charges = 0 dans un composé |
| Colonne du tableau | Donne le nombre d'électrons de valence |
