# 07 – Objectifs et ressources

Cette séance introduit deux grandeurs physiques fondamentales pour le contrôle qualité en cosmétique : la **masse volumique** et la **densité**. Ces mesures simples permettent de vérifier la conformité d'un produit et de détecter d'éventuelles anomalies de fabrication.

---

## 🎯 Objectifs

### Notions abordées

| Notion | Définition |
|--------|------------|
| **Masse volumique (ρ)** | Rapport masse/volume : ρ = m/V |
| **Densité (d)** | Rapport ρ_substance / ρ_eau (sans unité) |
| **Flottabilité** | d < 1 → flotte ; d > 1 → coule |
| **Conformité** | Comparaison au cahier des charges |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Utiliser les formules ρ = m/V et d = ρ/ρ_eau |
| **Analyser** | Extraire les données d'un dossier technique |
| **Interpréter** | Donner du sens à une mesure de densité |
| **Argumenter** | Relier une mesure à une propriété ou un défaut |

## 🔧 Formules à retenir

| Formule | Utilisation |
|---------|-------------|
| **ρ = m / V** | Calculer la masse volumique |
| **d = ρ / ρ_eau** | Calculer la densité |
| **m = ρ × V** | Calculer une masse à partir du volume |
| **V = m / ρ** | Calculer un volume à partir de la masse |
