
# 23 – Objectifs et ressources

Cette séance est de type **🧭 Culture appareils** : elle introduit les concepts physiques liés aux ondes sonores et les relie directement aux appareils à ultrasons utilisés en institut d'esthétique.

---

## 🎯 Objectifs

### Notions abordées

| Notion | Contenu |
|--------|---------|
| **Onde mécanique** | Définition, propagation, besoin d'un milieu matériel |
| **Grandeurs caractéristiques** | Période T (s), fréquence f (Hz), longueur d'onde λ (m), célérité c (m/s) |
| **Relation fondamentale** | c = λ × f et T = 1/f |
| **Spectre acoustique** | Infrasons (< 20 Hz), sons audibles (20 Hz – 20 kHz), ultrasons (> 20 kHz) |
| **Applications esthétiques** | Spatule US (nettoyage), sonophorèse (pénétration d'actifs), cavitation (minceur) |
| **Sécurité** | Gel de contact, mouvement continu, 7 contre-indications principales |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Connaître T, f, λ, c et utiliser c = λ × f |
| **Analyser** | Lire une fiche technique d'appareil à ultrasons |
| **Interpréter** | Relier fréquence à profondeur de pénétration |
| **Communiquer** | Expliquer fonctionnement et sécurité à une cliente |
