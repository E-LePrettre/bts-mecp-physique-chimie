# 15 – Objectifs et ressources

Cette séance est une **séance hybride (3h)** : une première heure installe le **principe du titrage pH-métrique**, la **relation à l'équivalence** et les **solutions tampons**, puis deux heures de manipulation permettent de titrer un mélange allantoïne-urée et de conclure sur la conformité d'une formulation cosmétique.

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Titrage acido-basique** | Méthode de dosage par réaction chimique avec un réactif de concentration connue |
| **Courbe pH = f(V)** | Courbe à 3 zones : excès d'acide / équivalence (saut) / excès de base |
| **Équivalence** | Réactifs mélangés en proportions stœchiométriques : n(acide) = n(base) |
| **Relation à l'équivalence** | n(acide) = C(titrante) × V_E |
| **Méthodes de détermination de V_E** | Méthode des tangentes (graphique) ou de la dérivée (numérique) |
| **Solution tampon** | Acide faible + base conjuguée ; pH varie peu lors d'ajouts modérés |
| **Zone de fonctionnement d'un tampon** | pH ≈ pKa ± 1 |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Écrire la relation à l'équivalence ; identifier un tampon |
| **Analyser** | Décrire une courbe pH = f(V) ; identifier les 3 zones ; repérer V_E |
| **Interpréter** | Relier le résultat quantitatif à la formulation cosmétique |
| **Argumenter** | Conclure sur la conformité d'un lot (structure résultat → comparaison → décision) |
| **Communiquer** | Rédiger une conclusion professionnelle structurée |

## 🔬 Principe du titrage pH-métrique – Rappel visuel

```
        DISPOSITIF DE TITRAGE

        ┌───┐
        │   │ ← Burette : solution titrante (NaOH, concentration CONNUE)
        │   │   On verse mL par mL
        └─┬─┘
          │
          ▼
    ┌───────────┐
    │           │ ← Solution titrée (acide cosmétique, concentration INCONNUE)
    │  BÉCHER   │ ← Sonde pH-mètre (mesure le pH en continu)
    │           │ ← Agitateur magnétique (homogénéité)
    └───────────┘

        COURBE pH = f(V)

        ┌─────────────────────────────────────────────┐
        │  Zone 1 : pH varie lentement → acide excès  │
        │  Zone 2 : SAUT brutal → équivalence         │
        │  Zone 3 : pH varie lentement → base excès   │
        │                                             │
        │  À l'équivalence :                          │
        │  n(acide) = C(titrante) × VE                │
        │  ⚠️  VE doit être en LITRES                 │
        └─────────────────────────────────────────────┘
```

## 🧴 Solutions tampons en cosmétique

| Tampon | Composition | pH ≈ | Usage |
|--------|:-----------:|:----:|-------|
| Citrate | Acide citrique + citrate de Na | 3–6 | Stabilisation pH des crèmes |
| Lactate | Acide lactique + lactate de Na | 3–5 | Soins hydratants |
| Phosphate | H₂PO₄⁻ + HPO₄²⁻ | 6–8 | Tampons biologiques |

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Saut de pH = signal de l'équivalence | Identifier V_E sur la courbe |
| n(acide) = C(titrante) × V_E | Calculer la quantité de matière d'acide |
| m = n × M | Remonter à la masse de l'espèce titrée |
| Tampon = acide faible + base conjuguée | Reconnaître un tampon ; exclure les acides forts |
| pH tampon ≈ pKa ± 1 | Évaluer la plage d'efficacité d'un tampon |
| Conclusion : résultat → comparaison → décision | Posture E2 pour conclure sur la conformité |
