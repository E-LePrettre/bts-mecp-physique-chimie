# 14 – Objectifs et ressources

Cette séance introduit les **couples acide-base** selon Brønsted, le **pKa** et le **diagramme de prédominance**. Les élèves apprennent à relier le pH d'une formulation cosmétique à l'efficacité d'un actif (peeling, conservateur) en utilisant le diagramme de prédominance comme outil de décision.

---

## 🎯 Objectifs

### Notions abordées

| Notion | Description |
|--------|-------------|
| **Acide / Base (Brønsted)** | Acide = cède H⁺ ; Base = capte H⁺ |
| **Couple acide/base AH/A⁻** | Acide et base conjuguée liés par AH ⇌ A⁻ + H⁺ |
| **Réaction acide-base** | Transfert de H⁺ entre deux couples |
| **pKa** | Constante caractéristique d'un couple ; mesure la force de l'acide |
| **Diagramme de prédominance** | pH < pKa → AH prédomine ; pH > pKa → A⁻ prédomine |
| **Espèce amphotère** | Peut être acide OU base selon la réaction (ex. : eau, acides aminés) |

### Compétences E2 travaillées

| Compétence | Application |
|------------|-------------|
| **Mobiliser** | Identifier un couple A/B, écrire la demi-équation, donner le sens du pKa |
| **Analyser** | Lire un diagramme de prédominance |
| **Interpréter** | Relier pH et pKa à l'efficacité d'un actif |
| **Argumenter** | Justifier un choix de pH de formulation |

## 🔬 Couples acide-base en cosmétique – Rappel visuel

```
        DIAGRAMME DE PRÉDOMINANCE
        
        pH < pKa  →  Forme ACIDE (AH) prédomine
        pH = pKa  →  50% AH / 50% A⁻
        pH > pKa  →  Forme BASIQUE (A⁻) prédomine
        
        ┌─────────────────────────────────────────────┐
        │  Acide glycolique : pKa = 3,8               │
        │  → Actif (exfoliant) à pH < 3,8             │
        │  → Inactif à pH > 3,8                       │
        │                                             │
        │  Acide sorbique : pKa = 4,8                 │
        │  → Conservateur actif à pH < 4,8            │
        │  → Inactif à pH > 4,8                       │
        └─────────────────────────────────────────────┘
```

## 🧪 pKa d'acides cosmétiques courants

| Couple AH / A⁻ | pKa | Usage cosmétique |
|:-:|:---:|:-:|
| Acide salicylique / Salicylate | 3,0 | Anti-acné (BHA) |
| Acide citrique / Citrate | 3,1 | Ajusteur de pH |
| Acide glycolique / Glycolate | 3,8 | Peeling AHA |
| Acide lactique / Lactate | 3,9 | Peeling doux |
| Acide benzoïque / Benzoate | 4,2 | Conservateur |
| Acide sorbique / Sorbate | 4,8 | Conservateur |

## 🔑 Points clés

| Règle | Application |
|-------|-------------|
| Acide = cède H⁺ | Identifier le rôle dans une réaction |
| Base = capte H⁺ | Identifier le rôle dans une réaction |
| pKa petit → acide fort | Comparer la force des acides |
| pH < pKa → AH | Prévoir l'efficacité d'un actif |
| pH > pKa → A⁻ | Prévoir l'inactivité d'un actif |
| Amphotère = les deux rôles | Eau, acides aminés |
