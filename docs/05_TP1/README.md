# 05 – Objectifs et ressources

Ce premier TP de l'année met en pratique les notions de **dissolution** (S02), **concentration** (S03) et **dilution** (S04). C'est une séance fondamentale pour acquérir les gestes de laboratoire.

---

## 🎯 Objectifs

### Objectifs scientifiques

* Préparer une **solution mère par dissolution** (pesée + ajustement)
* Réaliser des **dilutions** pour obtenir une gamme de concentrations
* Utiliser une **échelle de teinte** pour estimer une concentration inconnue
* Vérifier la **conformité** d'un produit par rapport à un cahier des charges

### Objectifs méthodologiques (E2)

* **Manipuler** avec rigueur (pesée, pipetage, ajustement)
* **Analyser** : exploiter une gamme étalon
* **Communiquer** : rédiger un compte-rendu de TP structuré

---

## 🧠 Compétences travaillées

* **Organiser** : préparer son poste, anticiper les étapes
* **Manipuler** : utiliser la verrerie jaugée avec précision
* **Analyser** : comparer, estimer, conclure
* **Communiquer** : rédiger un bilan de TP
